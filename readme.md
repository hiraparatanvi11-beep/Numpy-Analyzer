## 📌 About The Project

**NumPy Analyzer** is a menu-driven Python application developed using the NumPy library. It allows users to create and analyze NumPy arrays and perform different mathematical, statistical, and array manipulation operations.

The project provides a simple menu where users can select an operation, enter the required values, and view the results in the terminal.

---

## 🎯 Project Objectives

- To understand NumPy arrays and their dimensions.
- To perform mathematical operations on arrays.
- To learn array indexing and slicing.
- To combine and split arrays.
- To perform searching, sorting, and filtering.
- To calculate statistical values using NumPy.
- To understand exception handling in Python.

## 💻 Installation and Execution

### Step 1: Install Python

Download and install Python from the official website.

https://www.python.org/downloads/

### Step 2: Install NumPy

Open the terminal and execute:

```bash
pip install numpy
```

### Step 3: Run the Project

Open the project folder in Visual Studio Code and execute:

```bash
python NumPy_Analyzer.py
```

### Step 4: Select an Operation

Choose an option from the main menu, enter the required values, and view the result.
